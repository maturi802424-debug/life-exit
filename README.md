# LIFE EXIT — 人生の出口

3Dの暗い通路を歩きながら、人生の8領域に潜む「異変」に気づくオリジナル体験型Webゲームです。

## 遊び方
- 異変を感じたら「引き返す」
- 異変がなければ「進む」
- 正解すると現在地が1つ進みます
- 間違えると0へ戻ります
- 8まで到達すると出口です

## 人生の8テーマ
健康 / 人間関係 / 自己成長 / 仕事 / 経済 / 空間・環境 / 自由な時間 / 貢献

## 技術
Three.js / WebGL / Web Audio API / HTML / CSS / JavaScript

PCとスマートフォンのブラウザに対応したプロトタイプです。
